# Leetcode_Java

LeetCode 刷题记录，使用 Java 实现。

## 环境

- JDK: 17
- 编辑器: IntelliJ IDEA

## 目录约定

```
src/
├── easy/          简单题
├── medium/        中等题
└── hard/          困难题
```

每个题解文件建议命名为 `题号_题目名.java`，例如 `0001_TwoSum.java`，
文件内包含题目链接与思路注释。

## 提交规范

```
feat: 新增 0001 Two Sum 题解
fix:  修正 0015 三数之和边界处理
docs: 补充 README 目录说明
```

## 常用命令

```bash
git status                    # 查看改动
git add .                     # 加入暂存区
git commit -m "feat: ..."     # 提交
git push                      # 推送到 GitHub
```
